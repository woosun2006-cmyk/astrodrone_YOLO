# Jetson Nano CPU/GPU 전원 부하 시험

> 최종 업데이트: **2026-08-06**

Jetson Nano의 CPU와 CUDA GPU에 동시에 부하를 주면서 다음 항목을 1초 간격으로 확인하고 기록하는 프로그램이다.

- CPU 및 GPU 사용률
- GPU 클럭
- CPU, GPU, PMIC 온도
- 5V 입력 전압, 입력 전류 및 전체 소비전력
- CPU/GPU 전원 레일별 전압, 전류 및 소비전력

기본 안전 온도는 85°C이며, 이 온도에 도달하면 부하 시험을 자동으로 중지한다.

## HDMI 대시보드 실행

Jetson에 연결된 HDMI 화면에 대시보드를 띄우는 명령어:

```sh
/home/astro/jetson_power_test/launch_dashboard.sh
```

또는 Jetson 바탕화면의 **Jetson Power Monitor** 아이콘을 실행한다. `sudo`와 관리자 비밀번호는 필요하지 않다. 일반 사용자로 대시보드를 실행하고, 전원 정보는 Jetson에서 실행 중인 `jtop` 센서 서비스를 통해 읽는다.

대시보드에서는 다음 기능을 사용할 수 있다.

- 실시간 CPU/GPU 사용률, 온도 및 전원 상태 표시
- 1분, 5분, 10분 또는 15분 시험 선택
- CPU 목표 80%, 85% 또는 90% 선택
- GPU 평균 사용률을 약 85%로 자동 조절
- 부하 시험 시작 및 수동 중지
- 저전압 및 과열 상태 표시

기본 설정은 **10분, CPU 85%, GPU 85%**이다. 시험 중 다른 프로그램의 CPU/GPU 사용량이 변하면 실제 사용률을 확인하면서 부하를 자동으로 증감한다. 따라서 표시되는 값은 부하 프로그램만의 사용률이 아니라 Jetson 전체 시스템 사용률이다.

## 터미널에서 실행

대시보드 없이 기본 10분 시험을 실행하려면:

```sh
cd /home/astro/jetson_power_test
./run_power_test.sh
```

직접 설정하려면:

```sh
python3 /home/astro/jetson_power_test/monitor.py \
  --seconds 300 \
  --target 85 \
  --gpu-target 85 \
  --log /home/astro/jetson_power_test/power_test_manual.csv
```

## 로그

대시보드 시험 로그는 `logs/` 디렉터리에 다음과 같은 이름으로 저장된다.

```text
power_test_YYYYMMDD_HHMMSS.csv
power_test_YYYYMMDD_HHMMSS_stress.log
```

CSV는 매초 즉시 기록한 뒤 디스크에 동기화한다. 정상 종료된 로그의 마지막 행에는 `시험 완료`와 종료 코드 `0`이 기록된다. 사용자가 중지하면 `사용자가 중지함`이 기록된다. 전원이 갑자기 끊기면 이미 동기화된 샘플은 남지만 정상 종료 행은 존재하지 않을 수 있다.

`*_stress.log`에는 CUDA 부하 프로그램의 시작, 정상 종료 또는 오류 정보가 기록된다.

## 보존된 기준 시험 로그

2026-08-06에 전원 연결 방식별 비교를 위해 다음 두 시험 로그를 보존했다.

| 전원 연결 | 로그 파일 | 시험 시간 및 종료 | 평균 입력 전압 | CPU 평균 | GPU 평균 |
|---|---|---:|---:|---:|---:|
| DC 타입 | `logs/power_test_20260806_053607.csv` | 약 5분, 정상 완료 | 4.945V | 70.5% | 81.0% |
| USB-A 타입, 85% 보정 | `logs/power_test_20260806_063636.csv` | 약 37초, 사용자 중지 | 4.512V | 85.8% | 85.5% |

각 CSV와 같은 이름의 `*_stress.log`도 함께 보존한다. USB-A 시험은 CPU/GPU 목표 보정 확인용으로 사용자가 수동 중지한 짧은 시험이며, 5분 정상 완료 시험이 아니다.

## 결과 판단

- 워밍업 이후 CPU와 GPU 평균이 선택한 목표의 약 ±5% 범위인지 확인한다.
- GPU는 MAXN 모드에서 보통 921.6MHz까지 동작한다.
- 5V 입력 전압이 한 번이라도 4.75V 미만이면 전원공급기, 케이블 또는 커넥터 문제로 판단한다.
- 재부팅, 멈춤, CUDA 오류, 과열 자동 중지 또는 비정상 종료가 없어야 한다.
- 짧은 시험 통과는 해당 시간과 연결 상태에서만 안정적이었다는 의미다. 실제 비행 환경의 모터·ESC 잡음과 매우 짧은 전압 강하는 별도 시험이나 오실로스코프로 확인해야 한다.

## 전원 및 안전 주의사항

- 시험 전에 작업 중인 파일을 저장한다. 전원 공급이 부족하면 Jetson이 재부팅되거나 멈출 수 있다.
- Jetson Nano에는 안정화된 5V 전원을 공급한다.
- 부하 중 입력 전압을 4.75V 이상으로 유지한다.
- 12V 이상의 배터리 전압을 Jetson에 직접 연결하지 않는다. 반드시 적절한 5V DC-DC/BEC를 사용한다.
- 최초 장시간 시험은 자리를 비우지 말고 냉각팬과 실제 장착 환경을 확인한다.

## 주요 파일

- `dashboard.py`: HDMI 그래픽 대시보드
- `launch_dashboard.sh`: HDMI 대시보드 실행 스크립트
- `monitor.py`: 터미널 모니터 및 로그 기록
- `jetson_stress.cu`: CPU/CUDA 부하 생성 코드
- `jetson_stress`: 빌드된 부하 실행 파일
- `build.sh`: CUDA 부하 프로그램 빌드
- `run_power_test.sh`: 기본 터미널 시험 실행
- `logs/`: 실제 시험 CSV 및 CUDA 진단 로그 보관
